# Smart City AI System

An AI-based smart city traffic management system designed
to optimize traffic flow, reduce congestion, and prioritize
emergency vehicles.

## Features

- Traffic congestion detection using Fuzzy Logic
- Emergency vehicle prioritization
- Rule-Based Expert System
- Traffic signal optimization using Genetic Algorithm
- Uncertainty handling for traffic sensor data
- Explainable AI
- Fairness analysis

## Technologies

- Python
- Artificial Intelligence
- Fuzzy Logic
- Genetic Algorithm
- Rule-Based Systems
- Streamlit
- NetworkX
- Matplotlib
